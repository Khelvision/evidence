# KhelSutra evaluation media terms

No evaluation media is included in the framework preview.

When a release adds separately licensed evaluation media, its release-specific grant must state the exact
sample identifiers and permitted uses. The intended default grant permits downloading the named samples,
running local evaluation, and publishing predictions and aggregate metrics by sample ID.

Unless a release-specific grant says otherwise, evaluation media may **not** be used to train or tune a
model, rehosted or redistributed, used in advertising, used to identify a person, or transformed for an
unrelated purpose. These terms do not grant rights to model weights, labels, trademarks, or third-party
content. If a release has no exact grant, the media is not available for public use.
