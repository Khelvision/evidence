# Contributing

Contributions are welcome when they preserve the evidence boundary.

1. Run the full local quality gate from the README.
2. Add or update tests for every schema or scoring change.
3. Use synthetic fixtures unless the repository contains an exact publication grant for the media.
4. Put self-run results in the community registry. Do not edit the official registry in the same change.
5. State failures, exclusions, manual work, licensing uncertainty, and comparability limitations plainly.

Community registry entries are reviewed for contract validity and safety, not endorsed for model quality.
Do not include customer identity, private paths/endpoints, credentials, hidden labels, raw proprietary
implementation details, or media you cannot redistribute.
